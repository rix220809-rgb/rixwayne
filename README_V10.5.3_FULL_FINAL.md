# Our Memories V10.5.3 Full Final

這是完整專案版本，不是 Patch。

## 使用方式

1. 在 GitHub Desktop 先按 **Abort Merge**。
2. 關閉 GitHub Desktop。
3. 打開目前本機的 `rixwayne` 專案資料夾。
4. 備份後，刪除專案內原有檔案，但不要刪除隱藏的 `.git` 資料夾。
5. 將本壓縮檔內所有檔案完整複製到 `rixwayne` 專案根目錄。
6. 重新開啟 GitHub Desktop。
7. Commit：
   `V10.5.3 Full Final`
8. Push origin。
9. 等 GitHub Pages 部署完成，再強制重新整理網站。
