# Our Memories V10.5.3｜Cycle UI Redesign

## 這版只重做小舜頁 UI，不改經期、避孕藥或推播計算邏輯。

### 新版內容
- 經期狀態整合成一張資訊卡
- 平均週期、平均經期、預估日期改成三格統計
- 避孕藥首頁只顯示狀態，不再直接放日期輸入框
- 點「修改開始日期」後，以彈窗設定實際服藥 Day 1
- 本次經期控制改成單一主按鈕
- 補登過去經期預設收合
- 歷史資料改成精簡列表
- 手機與桌機版同步重新排版

## 更新方式
1. 將壓縮檔完整覆蓋目前 GitHub 專案。
2. GitHub Desktop Commit 並 Push。
3. 等 GitHub Pages 部署完成。
4. 強制重新整理網站；手機 PWA 請先完全關閉再開啟。

## 不需要執行 SQL
本版不新增資料表，也不需要更新 Edge Function。
